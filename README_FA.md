# Store Manager Pro — نسخه ویندوز

این پروژه نسخه بسته‌بندی‌شده و آماده Build از نرم‌افزار فعلی مدیریت فروشگاه است.

## امکانات حفظ‌شده
- مدیریت کالا، دسته‌بندی، برند و موجودی
- ورود و خروج انبار
- مشتریان و پروفایل مشتری
- فروش و تاریخچه فروش
- فاکتور
- فروش نقدی و اقساطی
- برنامه اقساط و ثبت چند پرداخت برای یک قسط
- گزارش‌ها و وضعیت اقساط عقب‌افتاده
- کاربران، نقش‌ها و سطح دسترسی
- تنظیمات فروشگاه
- پشتیبان‌گیری
- ثبت لاگ عملیات
- تقویم و نمایش تاریخ شمسی

## نکته مهم درباره نصب
برنامه برای اجرا روی Windows از Python استفاده نمی‌کند؛ پس از Build با PyInstaller یک فایل EXE مستقل ساخته می‌شود.

برای اینکه اطلاعات در Program Files ذخیره نشود، دیتابیس و لاگ‌ها در پوشه AppData کاربر نگهداری می‌شوند و دیتابیس قدیمی کنار برنامه در اولین اجرا به‌صورت خودکار مهاجرت می‌کند.

## ساخت نسخه Windows
روی یک سیستم Windows:

1. Python 3.11 یا جدیدتر را نصب کنید.
2. در صورت نیاز Inno Setup را نصب کنید.
3. فایل `build_windows.bat` را اجرا کنید.
4. فایل نصب در `dist-installer\StoreManagerPro_Setup.exe` ساخته می‌شود.

نام کاربری: `admin`
